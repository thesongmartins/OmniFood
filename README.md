# 🍽️ OmniFood – AI-Powered Healthy Meal Delivery Service

OmniFood is a responsive, modern landing page for a fictional AI-powered food subscription service. The website is designed to provide an engaging user experience across all devices, emphasizing healthy eating, convenience, and sustainability.

## ✨ Features

- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.
- **Interactive Navigation**: Smooth scrolling and sticky navigation for easy access.
- **Engaging Hero Section**: Captivating introduction with a clear call-to-action.
- **Step-by-Step Guide**: Visual representation of how the service works.
- **Meal Showcase**: Display of diverse meal options with nutritional information.
- **Customer Testimonials**: Realistic feedback to build trust with potential users.
- **Pricing Plans**: Clear and concise subscription options.
- **Contact Form**: Users can sign up or get in touch easily.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and accessibility.
- **CSS3**: Styling with Flexbox and Grid for layout.
- **JavaScript (ES6)**: Interactive elements and DOM manipulation.
- **Vercel**: Deployment and hosting.
